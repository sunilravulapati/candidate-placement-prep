# Question TCS_VER_245 — Explanation

**Correct Answer: Option B (has been working)**

### Topic
Verbal Ability > Sentence Improvement

### Question
Improve the underlined part of the sentence: 'He is working in this company since five years.'

### Options
- (A) worked
- (B) has been working
- (C) was working
- (D) No improvement

### Explanation
Option (B) is the correct answer. In Sentence Improvement, evaluating the given problem conditions confirms that "has been working" is the valid solution.
