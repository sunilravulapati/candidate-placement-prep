# Question TCS_VER_252 — Explanation

**Correct Answer: Option D (No improvement)**

### Topic
Verbal Ability > Sentence Improvement

### Question
Improve the underlined part of the sentence: 'She could not help but cry on hearing the news.'

### Options
- (A) help but crying
- (B) help to cry
- (C) help cried
- (D) No improvement

### Explanation
Option (D) is the correct answer. In Sentence Improvement, evaluating the given problem conditions confirms that "No improvement" is the valid solution.
