# Question TCS_VER_262 — Explanation

**Correct Answer: Option A (adversely affected)**

### Topic
Verbal Ability > Sentence Improvement

### Question
Improve the underlined part of the sentence: 'The new regulation affected adversely the small businesses.'

### Options
- (A) adversely affected
- (B) affected adverse
- (C) affected adversely on
- (D) No improvement

### Explanation
Option (A) is the correct answer. In Sentence Improvement, evaluating the given problem conditions confirms that "adversely affected" is the valid solution.
