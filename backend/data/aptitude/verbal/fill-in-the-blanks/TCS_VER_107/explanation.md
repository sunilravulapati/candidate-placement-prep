# Question TCS_VER_107 — Explanation

**Correct Answer: Option A (dilapidation)**

### Topic
Verbal Ability > Fill in the Blanks

### Question
The old building was in a state of complete _____; it had to be demolished.

### Options
- (A) dilapidation
- (B) repair
- (C) restoration
- (D) perfection

### Explanation
Option (A) is the correct answer. In Fill in the Blanks, evaluating the given problem conditions confirms that "dilapidation" is the valid solution.
