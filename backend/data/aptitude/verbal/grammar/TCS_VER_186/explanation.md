# Question TCS_VER_186 — Explanation

**Correct Answer: Option B (If it rains, we will cancel the match.)**

### Topic
Verbal Ability > Grammar

### Question
Which sentence uses the correct tense?

### Options
- (A) If it will rain, we will cancel the match.
- (B) If it rains, we will cancel the match.
- (C) If it rained, we will cancel the match.
- (D) If it rains, we cancel the match.

### Explanation
Option (B) is the correct answer. In Grammar, evaluating the given problem conditions confirms that "If it rains, we will cancel the match." is the valid solution.
