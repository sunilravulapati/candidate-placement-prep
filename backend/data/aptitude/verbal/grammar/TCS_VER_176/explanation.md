# Question TCS_VER_176 — Explanation

**Correct Answer: Option B (A number of students were absent today.)**

### Topic
Verbal Ability > Grammar

### Question
Identify the sentence with correct subject-verb agreement:

### Options
- (A) A number of students was absent today.
- (B) A number of students were absent today.
- (C) The number of students were absent today.
- (D) A number of student was absent.

### Explanation
Option (B) is the correct answer. In Grammar, evaluating the given problem conditions confirms that "A number of students were absent today." is the valid solution.
