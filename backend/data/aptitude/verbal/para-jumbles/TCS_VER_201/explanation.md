# Question TCS_VER_201 — Explanation

**Correct Answer: Option A (P-R-Q-S)**

### Topic
Verbal Ability > Para Jumbles

### Question
P: The internet has revolutionized communication. Q: Today, information can be shared globally in seconds. R: Before its invention, letters took weeks to travel between continents. S: This transformation has had both positive and negative consequences. Arrange P, Q, R, S in logical order:

### Options
- (A) P-R-Q-S
- (B) R-P-Q-S
- (C) P-Q-R-S
- (D) Q-P-R-S

### Explanation
Option (A) is the correct answer. In Para Jumbles, evaluating the given problem conditions confirms that "P-R-Q-S" is the valid solution.
