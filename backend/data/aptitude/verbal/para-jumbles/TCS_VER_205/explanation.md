# Question TCS_VER_205 — Explanation

**Correct Answer: Option A (P-Q-R-S)**

### Topic
Verbal Ability > Para Jumbles

### Question
P: Social media has connected people across the globe. Q: However, it has also become a platform for misinformation and cyberbullying. R: Users must therefore develop digital literacy skills. S: The key is to use it responsibly and critically. Arrange in logical order:

### Options
- (A) P-Q-R-S
- (B) Q-P-R-S
- (C) P-R-Q-S
- (D) Q-R-P-S

### Explanation
Option (A) is the correct answer. In Para Jumbles, evaluating the given problem conditions confirms that "P-Q-R-S" is the valid solution.
