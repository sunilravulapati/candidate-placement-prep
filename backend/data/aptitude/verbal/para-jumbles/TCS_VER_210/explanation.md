# Question TCS_VER_210 — Explanation

**Correct Answer: Option A (P-Q-R-S)**

### Topic
Verbal Ability > Para Jumbles

### Question
P: Plastic pollution is a growing environmental crisis. Q: Millions of tons of plastic waste end up in oceans each year. R: Marine animals mistake plastic debris for food, often fatally. S: Reducing single-use plastic is an urgent global necessity. Arrange in logical order:

### Options
- (A) P-Q-R-S
- (B) Q-P-R-S
- (C) R-P-Q-S
- (D) P-R-Q-S

### Explanation
Option (A) is the correct answer. In Para Jumbles, evaluating the given problem conditions confirms that "P-Q-R-S" is the valid solution.
