# Question TCS_VER_410 — Explanation

**Correct Answer: Option A (The bridge was built in 1990.)**

### Topic
Verbal Ability > Miscellaneous

### Question
Which is the correct passive of 'They built the bridge in 1990'?

### Options
- (A) The bridge was built in 1990.
- (B) The bridge is built in 1990.
- (C) The bridge has been built in 1990.
- (D) The bridge was build in 1990.

### Explanation
Option (A) is the correct answer. In Miscellaneous, evaluating the given problem conditions confirms that "The bridge was built in 1990." is the valid solution.
