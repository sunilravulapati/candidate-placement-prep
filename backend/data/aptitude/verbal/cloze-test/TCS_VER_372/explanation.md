# Question TCS_VER_372 — Explanation

**Correct Answer: Option A (prosperous)**

### Topic
Verbal Ability > Cloze Test

### Question
Education is the most powerful weapon one can use to change the world. It empowers individuals, reduces poverty, and builds a foundation for a _____ (2) society. SELECT WORD FOR BLANK (2):

### Options
- (A) prosperous
- (B) declining
- (C) stagnant
- (D) corrupted

### Explanation
Option (A) is the correct answer. In Cloze Test, evaluating the given problem conditions confirms that "prosperous" is the valid solution.
