# Question TCS_VER_378 — Explanation

**Correct Answer: Option A (replacing)**

### Topic
Verbal Ability > Cloze Test

### Question
The global economy is undergoing a major transition. Automation and AI are _____ (2) traditional jobs, forcing workers to acquire new skills. SELECT WORD FOR BLANK (2):

### Options
- (A) replacing
- (B) creating
- (C) preserving
- (D) protecting

### Explanation
Option (A) is the correct answer. In Cloze Test, evaluating the given problem conditions confirms that "replacing" is the valid solution.
