# Question TCS_VER_371 — Explanation

**Correct Answer: Option A (weapon)**

### Topic
Verbal Ability > Cloze Test

### Question
Education is the most powerful _____ (1) one can use to change the world. It empowers individuals, reduces poverty, and builds a foundation for a _____ (2) society. However, millions of children worldwide still lack _____ (3) to quality education. SELECT WORD FOR BLANK (1):

### Options
- (A) weapon
- (B) burden
- (C) problem
- (D) obstacle

### Explanation
Option (A) is the correct answer. In Cloze Test, evaluating the given problem conditions confirms that "weapon" is the valid solution.
