# Question TCS_VER_374 — Explanation

**Correct Answer: Option A (had)**

### Topic
Verbal Ability > Cloze Test

### Question
The city had grown rapidly. Skyscrapers now dominated the skyline where rice fields once _____ (2) stretched endlessly. SELECT WORD FOR BLANK (2):

### Options
- (A) had
- (B) would
- (C) were
- (D) get

### Explanation
Option (A) is the correct answer. In Cloze Test, evaluating the given problem conditions confirms that "had" is the valid solution.
