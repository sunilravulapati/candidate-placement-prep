# Question TCS_LOG_082 — Explanation

**Correct Answer: Option A (3)**

### Topic
Logical Reasoning > Seating Arrangement

### Question
In a circular arrangement of 8 people, if 4 people between A and B going clockwise, how many are there going counter-clockwise?

### Options
- (A) 3
- (B) 4
- (C) 5
- (D) 2

### Explanation
Option (A) is the correct answer. In Seating Arrangement, evaluating the given problem conditions confirms that "3" is the valid solution.
