# Question TCS_LOG_084 — Explanation

**Correct Answer: Option A (Black, Blue, Green, Yellow, Red)**

### Topic
Logical Reasoning > Seating Arrangement

### Question
5 boxes are stacked. Red is below yellow. Blue is above green. Green is above yellow. Black is at top. Order from top?

### Options
- (A) Black, Blue, Green, Yellow, Red
- (B) Black, Green, Blue, Yellow, Red
- (C) Blue, Black, Green, Yellow, Red
- (D) Black, Blue, Yellow, Green, Red

### Explanation
Option (A) is the correct answer. In Seating Arrangement, evaluating the given problem conditions confirms that "Black, Blue, Green, Yellow, Red" is the valid solution.
