# Question TCS_LOG_139 — Explanation

**Correct Answer: Option A (Only I follows)**

### Topic
Logical Reasoning > Statement and Conclusions

### Question
Statement: Some doctors are teachers. All teachers are graduates. Conclusion I: Some doctors are graduates. Conclusion II: All graduates are teachers.

### Options
- (A) Only I follows
- (B) Only II follows
- (C) Both follow
- (D) Neither follows

### Explanation
Option (A) is the correct answer. In Statement and Conclusions, evaluating the given problem conditions confirms that "Only I follows" is the valid solution.
