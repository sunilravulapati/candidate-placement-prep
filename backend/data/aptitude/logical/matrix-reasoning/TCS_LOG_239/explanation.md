# Question TCS_LOG_239 — Explanation

**Correct Answer: Option A (○)**

### Topic
Logical Reasoning > Matrix Reasoning

### Question
Row 1: △ ○ □. Row 2: ○ □ △. Row 3: □ △ ?

### Options
- (A) ○
- (B) △
- (C) □
- (D) ●

### Explanation
Option (A) is the correct answer. In Matrix Reasoning, evaluating the given problem conditions confirms that "○" is the valid solution.
