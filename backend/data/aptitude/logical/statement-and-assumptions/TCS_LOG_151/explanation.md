# Question TCS_LOG_151 — Explanation

**Correct Answer: Option A (Only II is implicit)**

### Topic
Logical Reasoning > Statement and Assumptions

### Question
Statement: 'The railway station has been closed due to maintenance.' Assumption I: Passengers know of an alternative. Assumption II: Maintenance requires closure.

### Options
- (A) Only II is implicit
- (B) Only I is implicit
- (C) Both are implicit
- (D) Neither is implicit

### Explanation
Option (A) is the correct answer. In Statement and Assumptions, evaluating the given problem conditions confirms that "Only II is implicit" is the valid solution.
