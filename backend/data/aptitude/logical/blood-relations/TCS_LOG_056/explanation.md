# Question TCS_LOG_056 — Explanation

**Correct Answer: Option A (Mother)**

### Topic
Logical Reasoning > Blood Relations

### Question
If A's father's only son is B, and B's mother is C, then C is A's ___

### Options
- (A) Mother
- (B) Aunt
- (C) Sister
- (D) Grandmother

### Explanation
Option (A) is the correct answer. In Blood Relations, evaluating the given problem conditions confirms that "Mother" is the valid solution.
