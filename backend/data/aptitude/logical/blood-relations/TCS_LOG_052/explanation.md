# Question TCS_LOG_052 — Explanation

**Correct Answer: Option A (Grandfather)**

### Topic
Logical Reasoning > Blood Relations

### Question
If P is Q's father, Q is R's mother, R is S's sibling, then P is S's?

### Options
- (A) Grandfather
- (B) Father
- (C) Uncle
- (D) Grandmother

### Explanation
Option (A) is the correct answer. In Blood Relations, evaluating the given problem conditions confirms that "Grandfather" is the valid solution.
