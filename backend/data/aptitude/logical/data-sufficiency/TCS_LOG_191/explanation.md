# Question TCS_LOG_191 — Explanation

**Correct Answer: Option A (Statement II alone is sufficient)**

### Topic
Logical Reasoning > Data Sufficiency

### Question
Is x > 0? (I) x2 = 4 (II) x + 1 > 0

### Options
- (A) Statement II alone is sufficient
- (B) Statement I alone is sufficient
- (C) Both together are sufficient
- (D) Neither is sufficient

### Explanation
Option (A) is the correct answer. In Data Sufficiency, evaluating the given problem conditions confirms that "Statement II alone is sufficient" is the valid solution.
