# Question TCS_LOG_199 — Explanation

**Correct Answer: Option A (Both statements together might not be sufficient without knowing if A, B, C are collinear)**

### Topic
Logical Reasoning > Data Sufficiency

### Question
What is the distance from A to C? (I) Distance from A to B is 5 km. (II) Distance from B to C is 7 km.

### Options
- (A) Both statements together might not be sufficient without knowing if A, B, C are collinear
- (B) Both alone
- (C) Only II
- (D) Only I

### Explanation
Option (A) is the correct answer. In Data Sufficiency, evaluating the given problem conditions confirms that "Both statements together might not be sufficient without knowing if A, B, C are collinear" is the valid solution.
