# Question TCS_LOG_206 — Explanation

**Correct Answer: Option A (Valid disjunctive syllogism)**

### Topic
Logical Reasoning > Critical Reasoning

### Question
'Either the train is on time, or we will be late. We are not late. Therefore, the train was on time.' This is an example of:

### Options
- (A) Valid disjunctive syllogism
- (B) Invalid argument
- (C) Circular reasoning
- (D) Hasty generalization

### Explanation
Option (A) is the correct answer. In Critical Reasoning, evaluating the given problem conditions confirms that "Valid disjunctive syllogism" is the valid solution.
