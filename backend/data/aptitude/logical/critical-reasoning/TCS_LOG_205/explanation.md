# Question TCS_LOG_205 — Explanation

**Correct Answer: Option A (Some politicians are not corrupt)**

### Topic
Logical Reasoning > Critical Reasoning

### Question
If the statement 'All politicians are corrupt' is false, which is definitely true?

### Options
- (A) Some politicians are not corrupt
- (B) No politician is corrupt
- (C) All politicians are honest
- (D) Politicians are rarely corrupt

### Explanation
Option (A) is the correct answer. In Critical Reasoning, evaluating the given problem conditions confirms that "Some politicians are not corrupt" is the valid solution.
