# Question TCS_LOG_204 — Explanation

**Correct Answer: Option A (Invalid - affirming the consequent)**

### Topic
Logical Reasoning > Critical Reasoning

### Question
Argument: 'Every student who passed the exam studied hard. Priya studied hard.' Conclusion: 'Priya passed the exam.' This argument is:

### Options
- (A) Invalid - affirming the consequent
- (B) Valid deductive argument
- (C) Valid inductive argument
- (D) Sound and valid

### Explanation
Option (A) is the correct answer. In Critical Reasoning, evaluating the given problem conditions confirms that "Invalid - affirming the consequent" is the valid solution.
