# Question TCS_LOG_209 — Explanation

**Correct Answer: Option A (A paradox)**

### Topic
Logical Reasoning > Critical Reasoning

### Question
A man says, 'I always lie.' This statement is:

### Options
- (A) A paradox
- (B) True
- (C) False
- (D) A valid claim

### Explanation
Option (A) is the correct answer. In Critical Reasoning, evaluating the given problem conditions confirms that "A paradox" is the valid solution.
