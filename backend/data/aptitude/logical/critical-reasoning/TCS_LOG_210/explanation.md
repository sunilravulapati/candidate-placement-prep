# Question TCS_LOG_210 — Explanation

**Correct Answer: Option A (Some politicians are not honest)**

### Topic
Logical Reasoning > Critical Reasoning

### Question
Which conclusion follows from: 'No honest person is wealthy. Some politicians are wealthy.'?

### Options
- (A) Some politicians are not honest
- (B) All politicians are dishonest
- (C) No politician is honest
- (D) Wealthy people are dishonest

### Explanation
Option (A) is the correct answer. In Critical Reasoning, evaluating the given problem conditions confirms that "Some politicians are not honest" is the valid solution.
