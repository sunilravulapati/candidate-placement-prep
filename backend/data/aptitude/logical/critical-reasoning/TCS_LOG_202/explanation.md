# Question TCS_LOG_202 — Explanation

**Correct Answer: Option A (Correlation is mistaken for causation)**

### Topic
Logical Reasoning > Critical Reasoning

### Question
Argument: 'Sales of ice cream rise when drowning accidents increase. Therefore, eating ice cream causes drowning.' The flaw is:

### Options
- (A) Correlation is mistaken for causation
- (B) The sample size is too small
- (C) The argument is circular
- (D) The conclusion is irrelevant

### Explanation
Option (A) is the correct answer. In Critical Reasoning, evaluating the given problem conditions confirms that "Correlation is mistaken for causation" is the valid solution.
