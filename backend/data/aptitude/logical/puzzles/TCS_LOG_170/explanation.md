# Question TCS_LOG_170 — Explanation

**Correct Answer: Option A (A river)**

### Topic
Logical Reasoning > Puzzles

### Question
What can run but never walk, has a mouth but never talks, has a head but never weeps?

### Options
- (A) A river
- (B) A road
- (C) A clock
- (D) A book

### Explanation
Option (A) is the correct answer. In Puzzles, evaluating the given problem conditions confirms that "A river" is the valid solution.
