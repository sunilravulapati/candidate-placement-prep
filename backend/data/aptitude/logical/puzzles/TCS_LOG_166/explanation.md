# Question TCS_LOG_166 — Explanation

**Correct Answer: Option A (4)**

### Topic
Logical Reasoning > Puzzles

### Question
A man has 3 daughters. Each daughter has one brother. How many children does the man have?

### Options
- (A) 4
- (B) 6
- (C) 3
- (D) 5

### Explanation
Option (A) is the correct answer. In Puzzles, evaluating the given problem conditions confirms that "4" is the valid solution.
