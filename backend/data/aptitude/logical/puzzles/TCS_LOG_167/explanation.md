# Question TCS_LOG_167 — Explanation

**Correct Answer: Option A (90)**

### Topic
Logical Reasoning > Puzzles

### Question

### Options

### Explanation
Option (A) is the correct answer. In Puzzles, evaluating the given problem conditions confirms that "90" is the valid solution.
