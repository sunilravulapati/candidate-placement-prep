# Question TCS_LOG_160 — Explanation

**Correct Answer: Option A (Roosters don't lay eggs)**

### Topic
Logical Reasoning > Puzzles

### Question
If a rooster lays an egg on the peak of a roof, which way does it roll?

### Options
- (A) Roosters don't lay eggs
- (B) It rolls left
- (C) It rolls right
- (D) It stays put

### Explanation
Option (A) is the correct answer. In Puzzles, evaluating the given problem conditions confirms that "Roosters don't lay eggs" is the valid solution.
