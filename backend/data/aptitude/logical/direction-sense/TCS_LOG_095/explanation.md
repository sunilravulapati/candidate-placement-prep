# Question TCS_LOG_095 — Explanation

**Correct Answer: Option A (West)**

### Topic
Logical Reasoning > Direction Sense

### Question
In a city, roads run North-South and East-West. If you face North and turn left, you face:

### Options
- (A) West
- (B) East
- (C) South
- (D) North

### Explanation
Option (A) is the correct answer. In Direction Sense, evaluating the given problem conditions confirms that "West" is the valid solution.
