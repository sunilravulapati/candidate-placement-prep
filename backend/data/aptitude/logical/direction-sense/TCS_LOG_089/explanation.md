# Question TCS_LOG_089 — Explanation

**Correct Answer: Option A (5m East)**

### Topic
Logical Reasoning > Direction Sense

### Question
Ram walks 5m North, turns left 3m, turns left 5m, turns right 2m. How far from start, facing which direction?

### Options
- (A) 5m East
- (B) 5m West
- (C) 3m East
- (D) 2m East

### Explanation
Option (A) is the correct answer. In Direction Sense, evaluating the given problem conditions confirms that "5m East" is the valid solution.
