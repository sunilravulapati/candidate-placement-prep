# Question TCS_LOG_091 — Explanation

**Correct Answer: Option A (East)**

### Topic
Logical Reasoning > Direction Sense

### Question
Starting West, turn right, then turn right again. Which direction?

### Options
- (A) East
- (B) West
- (C) North
- (D) South

### Explanation
Option (A) is the correct answer. In Direction Sense, evaluating the given problem conditions confirms that "East" is the valid solution.
