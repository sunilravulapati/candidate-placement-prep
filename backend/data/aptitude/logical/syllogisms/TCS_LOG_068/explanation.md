# Question TCS_LOG_068 — Explanation

**Correct Answer: Option A (Only II follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
Some apples are mangoes. All mangoes are fruits. Conclusions: (I) All apples are fruits. (II) Some fruits are apples.

### Options
- (A) Only II follows
- (B) Only I follows
- (C) Both follow
- (D) Neither follows

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Only II follows" is the valid solution.
