# Question TCS_LOG_065 — Explanation

**Correct Answer: Option A (Neither follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
All roses are flowers. Some flowers are plants. Conclusions: (I) Some roses are plants. (II) All plants are flowers.

### Options
- (A) Neither follows
- (B) Only I follows
- (C) Only II follows
- (D) Both follow

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Neither follows" is the valid solution.
