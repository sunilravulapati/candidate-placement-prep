# Question TCS_LOG_071 — Explanation

**Correct Answer: Option A (Neither follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
All students are learners. Some learners are teachers. Conclusions: (I) Some students are teachers. (II) No teacher is a student.

### Options
- (A) Neither follows
- (B) Only I follows
- (C) Only II follows
- (D) Both follow

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Neither follows" is the valid solution.
