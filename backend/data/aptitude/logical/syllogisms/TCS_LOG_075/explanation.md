# Question TCS_LOG_075 — Explanation

**Correct Answer: Option A (Only II follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
All cars are vehicles. All buses are vehicles. Conclusions: (I) All cars are buses. (II) Some vehicles are cars.

### Options
- (A) Only II follows
- (B) Only I follows
- (C) Both follow
- (D) Neither follows

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Only II follows" is the valid solution.
