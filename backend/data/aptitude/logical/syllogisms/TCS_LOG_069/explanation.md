# Question TCS_LOG_069 — Explanation

**Correct Answer: Option A (Only I follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
All metals are conductors. Copper is a metal. Conclusions: (I) Copper is a conductor. (II) All conductors are metals.

### Options
- (A) Only I follows
- (B) Only II follows
- (C) Both follow
- (D) Neither follows

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Only I follows" is the valid solution.
