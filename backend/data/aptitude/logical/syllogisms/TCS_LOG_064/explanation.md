# Question TCS_LOG_064 — Explanation

**Correct Answer: Option A (Only I follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
Some cats are dogs. All dogs are horses. Conclusions: (I) Some cats are horses. (II) All horses are dogs.

### Options
- (A) Only I follows
- (B) Only II follows
- (C) Both follow
- (D) Neither follows

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Only I follows" is the valid solution.
