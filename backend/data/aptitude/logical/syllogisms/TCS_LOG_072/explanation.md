# Question TCS_LOG_072 — Explanation

**Correct Answer: Option A (Only I follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
Some mountains are rivers. All rivers are oceans. Conclusions: (I) Some mountains are oceans. (II) All oceans are rivers.

### Options
- (A) Only I follows
- (B) Both follow
- (C) Only II follows
- (D) Neither follows

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Only I follows" is the valid solution.
