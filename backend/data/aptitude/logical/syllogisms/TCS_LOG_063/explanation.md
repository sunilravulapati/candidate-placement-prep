# Question TCS_LOG_063 — Explanation

**Correct Answer: Option A (Only II follows)**

### Topic
Logical Reasoning > Syllogisms

### Question
No table is chair. All chairs are sofas. Conclusions: (I) No sofa is table. (II) Some sofas are chairs.

### Options
- (A) Only II follows
- (B) Only I follows
- (C) Both follow
- (D) Neither follows

### Explanation
Option (A) is the correct answer. In Syllogisms, evaluating the given problem conditions confirms that "Only II follows" is the valid solution.
