# Question TCS_LOG_026 — Explanation

**Correct Answer: Option B (APPLY)**

### Topic
Logical Reasoning > Coding-Decoding

### Question
In a code, APPLE = 12234. What is 12241?

### Options
- (A) APPLA
- (B) APPLY
- (C) APPEA
- (D) APPEL

### Explanation
Option (B) is the correct answer. In Coding-Decoding, evaluating the given problem conditions confirms that "APPLY" is the valid solution.
