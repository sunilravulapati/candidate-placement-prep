# Question TCS_LOG_031 — Explanation

**Correct Answer: Option A (9)**

### Topic
Logical Reasoning > Coding-Decoding

### Question
If in a code, 'go for win' means 135, 'for the game' means 259, 'win the match' means 167, then 'game' is coded as:

### Options
- (A) 9
- (B) 5
- (C) 2
- (D) 3

### Explanation
Option (A) is the correct answer. In Coding-Decoding, evaluating the given problem conditions confirms that "9" is the valid solution.
