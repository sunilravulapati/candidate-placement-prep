# Question TCS_LOG_030 — Explanation

**Correct Answer: Option A (Sum of positions of letters)**

### Topic
Logical Reasoning > Coding-Decoding

### Question
If LAPTOP = 23 and KEYBOARD = 31, what does the code represent?

### Options
- (A) Sum of positions of letters
- (B) Number of letters × 2
- (C) Sum of alternate letters
- (D) Product of vowels

### Explanation
Option (A) is the correct answer. In Coding-Decoding, evaluating the given problem conditions confirms that "Sum of positions of letters" is the valid solution.
