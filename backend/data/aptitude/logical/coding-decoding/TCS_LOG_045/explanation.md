# Question TCS_LOG_045 — Explanation

**Correct Answer: Option A (ZQHMA)**

### Topic
Logical Reasoning > Coding-Decoding

### Question
If NORTH is coded as UQHMA, then SOUTH is coded as ?

### Options
- (A) ZQHMA
- (B) ZQHNA
- (C) YQHNA
- (D) YQHMA

### Explanation
Option (A) is the correct answer. In Coding-Decoding, evaluating the given problem conditions confirms that "ZQHMA" is the valid solution.
