# Question TCS_LOG_399 — Explanation

**Correct Answer: Option C (Some R may not be Q)**

### Topic
Logical Reasoning > Logical

### Question
Which conclusion follows: No P is Q. All Q are R. Some R are S.

### Options
- (A) No P is R
- (B) Some S are Q
- (C) Some R may not be Q
- (D) All P are S

### Explanation
Option (C) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Some R may not be Q" is the valid solution.
