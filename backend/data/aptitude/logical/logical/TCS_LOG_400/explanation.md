# Question TCS_LOG_400 — Explanation

**Correct Answer: Option A (Ram works hard)**

### Topic
Logical Reasoning > Logical

### Question
Statement: All students work hard. Ram is a student. Conclusion?

### Options
- (A) Ram works hard
- (B) Ram is lazy
- (C) Students are smart
- (D) Cannot say

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Ram works hard" is the valid solution.
