# Question TCS_LOG_366 — Explanation

**Correct Answer: Option A (Wednesday)**

### Topic
Logical Reasoning > Logical

### Question
If the day before yesterday was Saturday, what day will be day after tomorrow?

### Options
- (A) Wednesday
- (B) Thursday
- (C) Tuesday
- (D) Friday

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Wednesday" is the valid solution.
