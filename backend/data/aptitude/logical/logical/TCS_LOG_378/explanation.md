# Question TCS_LOG_378 — Explanation

**Correct Answer: Option A (P>S)**

### Topic
Logical Reasoning > Logical

### Question
If P>Q, Q>R, R>S, then which is always true?

### Options
- (A) P>S
- (B) S>P
- (C) P=S
- (D) P<S

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "P>S" is the valid solution.
