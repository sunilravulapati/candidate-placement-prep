# Question TCS_LOG_372 — Explanation

**Correct Answer: Option A (John knows a lot)**

### Topic
Logical Reasoning > Logical

### Question
Statement: The more you read, the more you know. If John reads a lot, then?

### Options
- (A) John knows a lot
- (B) John will be smart
- (C) Reading is hard
- (D) Cannot determine

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "John knows a lot" is the valid solution.
