# Question TCS_LOG_284 — Explanation

**Correct Answer: Option A (Socrates is mortal)**

### Topic
Logical Reasoning > Logical

### Question
Syllogism: All men are mortal. Socrates is a man. Therefore?

### Options
- (A) Socrates is mortal
- (B) Socrates is immortal
- (C) All mortals are men
- (D) Socrates is not mortal

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Socrates is mortal" is the valid solution.
