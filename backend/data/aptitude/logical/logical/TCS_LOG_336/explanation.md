# Question TCS_LOG_336 — Explanation

**Correct Answer: Option C (Fire is dangerous in offices)**

### Topic
Logical Reasoning > Logical

### Question
Statement-Assumption: Statement: Install fire extinguishers in offices. Assumption?

### Options
- (A) Offices catch fire frequently
- (B) No one can put out fire
- (C) Fire is dangerous in offices
- (D) Both A and C

### Explanation
Option (C) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Fire is dangerous in offices" is the valid solution.
