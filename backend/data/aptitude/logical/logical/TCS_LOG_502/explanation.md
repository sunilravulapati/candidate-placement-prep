# Question TCS_LOG_502 — Explanation

**Correct Answer: Option A (Today is Tuesday)**

### Topic
Logical Reasoning > Logical

### Question
Logical: If today is not Tuesday, it is Thursday. Today is not Thursday. Therefore?

### Options
- (A) Today is Tuesday
- (B) Today is Wednesday
- (C) Cannot say
- (D) Today is Monday

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Today is Tuesday" is the valid solution.
