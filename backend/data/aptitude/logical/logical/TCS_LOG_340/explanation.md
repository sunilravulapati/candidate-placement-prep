# Question TCS_LOG_340 — Explanation

**Correct Answer: Option A (Honest)**

### Topic
Logical Reasoning > Logical

### Question
Critical reasoning: If only honest people get promoted and X got promoted, then X is?

### Options
- (A) Honest
- (B) Dishonest
- (C) Smart
- (D) Hard-working

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Honest" is the valid solution.
