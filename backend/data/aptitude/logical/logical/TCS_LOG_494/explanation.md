# Question TCS_LOG_494 — Explanation

**Correct Answer: Option A (Tiger is mammal)**

### Topic
Logical Reasoning > Logical

### Question
Statement: Cats are mammals. Tiger is a cat. Conclusion?

### Options
- (A) Tiger is mammal
- (B) Mammals are tigers
- (C) Some tigers aren't cats
- (D) Cannot say

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Tiger is mammal" is the valid solution.
