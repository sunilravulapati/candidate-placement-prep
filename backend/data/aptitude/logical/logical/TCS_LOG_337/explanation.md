# Question TCS_LOG_337 — Explanation

**Correct Answer: Option A (Broccoli is healthy)**

### Topic
Logical Reasoning > Logical

### Question
Statement-Conclusion: All vegetables are healthy. Broccoli is a vegetable. Conclusion?

### Options
- (A) Broccoli is healthy
- (B) All healthy things are vegetables
- (C) Some vegetables aren't healthy
- (D) Cannot conclude

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Broccoli is healthy" is the valid solution.
