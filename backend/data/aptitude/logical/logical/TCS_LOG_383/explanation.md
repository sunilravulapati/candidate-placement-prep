# Question TCS_LOG_383 — Explanation

**Correct Answer: Option A (Eagles are birds)**

### Topic
Logical Reasoning > Logical

### Question
Passage reasoning: Only birds can fly. Eagles can fly. Therefore?

### Options
- (A) Eagles are birds
- (B) Birds are eagles
- (C) Some birds can't fly
- (D) Eagles can't fly

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Eagles are birds" is the valid solution.
