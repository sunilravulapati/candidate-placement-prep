# Question TCS_LOG_474 — Explanation

**Correct Answer: Option A (This is fragile)**

### Topic
Logical Reasoning > Logical

### Question
Statement: All glass is fragile. This is glass. Conclusion?

### Options
- (A) This is fragile
- (B) All fragile is glass
- (C) Some glass is not fragile
- (D) Cannot say

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "This is fragile" is the valid solution.
