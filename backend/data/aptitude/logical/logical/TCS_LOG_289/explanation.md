# Question TCS_LOG_289 — Explanation

**Correct Answer: Option A (Monday)**

### Topic
Logical Reasoning > Logical

### Question
Calendar: A year has 365 days. If Jan 1 is Monday, what day is Dec 31?

### Options
- (A) Monday
- (B) Tuesday
- (C) Wednesday
- (D) Sunday

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Monday" is the valid solution.
