# Question TCS_LOG_434 — Explanation

**Correct Answer: Option A (5km East)**

### Topic
Logical Reasoning > Logical

### Question

### Options

- (B) 5km West

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "5km East" is the valid solution.
