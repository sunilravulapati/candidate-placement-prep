# Question TCS_LOG_283 — Explanation

**Correct Answer: Option A (Some flowers are beautiful)**

### Topic
Logical Reasoning > Logical

### Question
Syllogism: Some flowers are red. All red things are beautiful. Which is true?

### Options
- (A) Some flowers are beautiful
- (B) All flowers are beautiful
- (C) No flowers are beautiful
- (D) Cannot determine

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Some flowers are beautiful" is the valid solution.
