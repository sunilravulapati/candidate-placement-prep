# Question TCS_LOG_281 — Explanation

**Correct Answer: Option A (All cats are living beings)**

### Topic
Logical Reasoning > Logical

### Question
Syllogism: All cats are animals. All animals are living beings. Which is true?

### Options
- (A) All cats are living beings
- (B) All living beings are cats
- (C) No cats are living
- (D) Some cats are not living

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "All cats are living beings" is the valid solution.
