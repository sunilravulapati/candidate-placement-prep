# Question TCS_LOG_413 — Explanation

**Correct Answer: Option A (D,C,A,B)**

### Topic
Logical Reasoning > Logical

### Question
Floor puzzle: A lives above B, below C, D lives above C. Order top to bottom?

### Options
- (A) D,C,A,B
- (B) C,D,A,B
- (C) D,C,B,A
- (D) A,C,D,B

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "D,C,A,B" is the valid solution.
