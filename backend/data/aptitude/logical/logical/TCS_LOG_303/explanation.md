# Question TCS_LOG_303 — Explanation

**Correct Answer: Option A (2nd position)**

### Topic
Logical Reasoning > Logical

### Question
Seating: A, B, C, D sit in a row. A not next to C. B is between A and C. Where is B?

### Options
- (A) 2nd position
- (B) 1st
- (C) 3rd
- (D) 4th

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "2nd position" is the valid solution.
