# Question TCS_LOG_379 — Explanation

**Correct Answer: Option A (P≥Q)**

### Topic
Logical Reasoning > Logical

### Question
Data: P≠Q, Q<R, R≤P. Which is true?

### Options
- (A) P≥Q
- (B) Q≥R
- (C) R>P
- (D) Cannot say

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "P≥Q" is the valid solution.
