# Question TCS_LOG_282 — Explanation

**Correct Answer: Option A (No pen is paper)**

### Topic
Logical Reasoning > Logical

### Question
Syllogism: All pens are books. No book is paper. Which conclusion follows?

### Options
- (A) No pen is paper
- (B) Some pens are paper
- (C) All papers are pens
- (D) None of these

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "No pen is paper" is the valid solution.
