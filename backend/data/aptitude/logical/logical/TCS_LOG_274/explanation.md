# Question TCS_LOG_274 — Explanation

**Correct Answer: Option A (Uncle)**

### Topic
Logical Reasoning > Logical

### Question
Blood relation: M is N's brother. N is O's mother. O is P's daughter. How is M related to O?

### Options
- (A) Uncle
- (B) Brother
- (C) Father
- (D) Nephew

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Uncle" is the valid solution.
