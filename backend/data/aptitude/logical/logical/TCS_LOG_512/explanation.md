# Question TCS_LOG_512 — Explanation

**Correct Answer: Option A (Not necessarily a computer)**

### Topic
Logical Reasoning > Logical

### Question
Deduction: All computers need electricity. X needs electricity. X is?

### Options
- (A) Not necessarily a computer
- (B) A computer
- (C) A machine
- (D) Cannot determine

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Not necessarily a computer" is the valid solution.
