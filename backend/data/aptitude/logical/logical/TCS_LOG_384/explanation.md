# Question TCS_LOG_384 — Explanation

**Correct Answer: Option A (It did not rain)**

### Topic
Logical Reasoning > Logical

### Question
Conditional: If it rains, the match is cancelled. Match was not cancelled. Therefore?

### Options
- (A) It did not rain
- (B) It rained
- (C) Match was played
- (D) Cannot say

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "It did not rain" is the valid solution.
