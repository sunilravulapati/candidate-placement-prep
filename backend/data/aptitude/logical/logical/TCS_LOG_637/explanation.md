# Question TCS_LOG_637 — Explanation

**Correct Answer: Option A (3km East of start)**

### Topic
Logical Reasoning > Logical

### Question
Go N 5km, E 3km, S 5km. Where are you?

### Options
- (A) 3km East of start
- (B) 5km North
- (C) 3km West
- (D) At start

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "3km East of start" is the valid solution.
