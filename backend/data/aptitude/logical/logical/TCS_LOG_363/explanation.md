# Question TCS_LOG_363 — Explanation

**Correct Answer: Option D (Cannot conclude for chairs)**

### Topic
Logical Reasoning > Logical

### Question
Syllogism: No chairs are tables. All tables are wooden. Conclusion?

### Options
- (A) No chair is wooden
- (B) Some chairs are wooden
- (C) All wooden are tables
- (D) Cannot conclude for chairs

### Explanation
Option (D) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Cannot conclude for chairs" is the valid solution.
