# Question TCS_LOG_359 — Explanation

**Correct Answer: Option A (Cousin)**

### Topic
Logical Reasoning > Logical

### Question
Blood relation: If X is son of Y's uncle and Z is wife of Y. How is X related to Z's husband?

### Options
- (A) Cousin
- (B) Nephew
- (C) Brother
- (D) Uncle

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Cousin" is the valid solution.
