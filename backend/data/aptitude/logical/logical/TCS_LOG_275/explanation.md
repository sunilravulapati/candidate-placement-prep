# Question TCS_LOG_275 — Explanation

**Correct Answer: Option A (Husband)**

### Topic
Logical Reasoning > Logical

### Question
Blood relation: A is B's son. C is A's sister. D is C's mother. How is B related to D?

### Options
- (A) Husband
- (B) Brother
- (C) Father
- (D) Son

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Husband" is the valid solution.
