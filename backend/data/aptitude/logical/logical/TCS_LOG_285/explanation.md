# Question TCS_LOG_285 — Explanation

**Correct Answer: Option A (No dog is a bird)**

### Topic
Logical Reasoning > Logical

### Question
Syllogism: No birds are mammals. All dogs are mammals. Which is definitely true?

### Options
- (A) No dog is a bird
- (B) All birds are dogs
- (C) Some birds are dogs
- (D) None of above

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "No dog is a bird" is the valid solution.
