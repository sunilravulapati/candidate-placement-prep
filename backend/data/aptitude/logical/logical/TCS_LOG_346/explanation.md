# Question TCS_LOG_346 — Explanation

**Correct Answer: Option A (Both together)**

### Topic
Logical Reasoning > Logical

### Question
Data sufficiency: What is value of x? I: 2x+y=10. II: x-y=2. Which is sufficient?

### Options
- (A) Both together
- (B) Neither
- (C) Statement I
- (D) Statement II

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Both together" is the valid solution.
