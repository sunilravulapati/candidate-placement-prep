# Question TCS_LOG_428 — Explanation

**Correct Answer: Option A (No S is Q)**

### Topic
Logical Reasoning > Logical

### Question
Syllogism: All S are P. No P is Q. Therefore?

### Options
- (A) No S is Q
- (B) All Q are S
- (C) Some S are Q
- (D) Cannot say

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "No S is Q" is the valid solution.
