# Question TCS_LOG_382 — Explanation

**Correct Answer: Option A (1h)**

### Topic
Logical Reasoning > Logical

### Question
Distance: A and B are 100km apart. Trains start simultaneously at 40km/h and 60km/h. Meet after?

### Options
- (A) 1h
- (B) 2h
- (C) 1.5h
- (D) 0.5h

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "1h" is the valid solution.
