# Question TCS_LOG_276 — Explanation

**Correct Answer: Option A (South)**

### Topic
Logical Reasoning > Logical

### Question
Direction: A person walks 5 km North, turns right, walks 3 km, turns right again and walks 5 km. Which direction is he now?

### Options
- (A) South
- (B) East
- (C) West
- (D) North

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "South" is the valid solution.
