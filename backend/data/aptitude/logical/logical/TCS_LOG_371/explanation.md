# Question TCS_LOG_371 — Explanation

**Correct Answer: Option A (5)**

### Topic
Logical Reasoning > Logical

### Question
Coding: In a certain code 'sky is blue' = 315, 'blue is water' = 625, 'water is life' = 472. What is code for 'blue'?

### Options
- (A) 5
- (B) 2
- (C) 3
- (D) 6

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "5" is the valid solution.
