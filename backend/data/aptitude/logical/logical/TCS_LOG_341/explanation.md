# Question TCS_LOG_341 — Explanation

**Correct Answer: Option A (Some managers inspire)**

### Topic
Logical Reasoning > Logical

### Question
If some managers are leaders, and all leaders inspire, then?

### Options
- (A) Some managers inspire
- (B) No managers inspire
- (C) All inspire
- (D) Cannot say

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Some managers inspire" is the valid solution.
