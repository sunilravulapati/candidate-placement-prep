# Question TCS_LOG_620 — Explanation

**Correct Answer: Option A (Grandson)**

### Topic
Logical Reasoning > Logical

### Question
X has 2 sons Y and Z. Y is A's father. A is B's sister. B is X's?

### Options
- (A) Grandson
- (B) Granddaughter
- (C) Nephew
- (D) Son

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Grandson" is the valid solution.
