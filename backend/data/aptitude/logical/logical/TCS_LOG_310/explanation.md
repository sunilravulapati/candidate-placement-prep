# Question TCS_LOG_310 — Explanation

**Correct Answer: Option A (C)**

### Topic
Logical Reasoning > Logical

### Question
Puzzle: A is taller than B. C is taller than A. D is shorter than B. Tallest?

### Options

- (B) A

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "C" is the valid solution.
