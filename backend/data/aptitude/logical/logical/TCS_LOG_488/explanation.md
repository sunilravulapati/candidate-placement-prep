# Question TCS_LOG_488 — Explanation

**Correct Answer: Option A (Siblings/cousins)**

### Topic
Logical Reasoning > Logical

### Question
Blood rel: A's son is B. C is B's cousin. D is C's father. D and A are?

### Options
- (A) Siblings/cousins
- (B) Parent-child
- (C) Married
- (D) Unrelated

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Siblings/cousins" is the valid solution.
