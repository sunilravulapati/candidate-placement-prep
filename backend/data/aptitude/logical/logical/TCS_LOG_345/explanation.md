# Question TCS_LOG_345 — Explanation

**Correct Answer: Option A (Statement I alone)**

### Topic
Logical Reasoning > Logical

### Question
Data sufficiency: Is x>y? I: x=y+2. II: x+y=10. Which statement is sufficient?

### Options
- (A) Statement I alone
- (B) Statement II alone
- (C) Both together
- (D) Neither

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Statement I alone" is the valid solution.
