# Question TCS_LOG_338 — Explanation

**Correct Answer: Option A (Reduces mobility)**

### Topic
Logical Reasoning > Logical

### Question
Statement-Argument: Should all cars be banned in cities? For: Reduces pollution. Against?

### Options
- (A) Reduces mobility
- (B) Expensive to own
- (C) Hard to repair
- (D) Old models pollute less

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Reduces mobility" is the valid solution.
