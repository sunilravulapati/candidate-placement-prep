# Question TCS_LOG_343 — Explanation

**Correct Answer: Option A (Fruit)**

### Topic
Logical Reasoning > Logical

### Question
Puzzle: 3 boxes. Box A has fruit if Box C has toys. Box C has toys. What does Box A have?

### Options
- (A) Fruit
- (B) Toys
- (C) Books
- (D) Cannot tell

### Explanation
Option (A) is the correct answer. In Logical, evaluating the given problem conditions confirms that "Fruit" is the valid solution.
