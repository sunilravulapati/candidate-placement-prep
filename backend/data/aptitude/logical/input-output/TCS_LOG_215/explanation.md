**Correct Answer: Option A (Olleh Dlrow Tset)**

### Topic
Logical Reasoning > Input-Output

### Question

### Options
- (A) Olleh Dlrow Tset

### Explanation
Option (A) is the correct answer. In Input-Output, evaluating the given problem conditions confirms that "Olleh Dlrow Tset" is the valid solution.
