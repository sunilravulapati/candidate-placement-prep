# Question TCS_LOG_220 — Explanation

**Correct Answer: Option A (DER NER EUL)**

### Topic
Logical Reasoning > Input-Output

### Question
Input: RED GREEN BLUE. If all letters are reversed and only first 3 letters of each word taken. Output:

### Options
- (A) DER NER EUL
- (B) RED GRE BLU
- (C) DER EER ULB
- (D) EDR NEE EUL

### Explanation
Option (A) is the correct answer. In Input-Output, evaluating the given problem conditions confirms that "DER NER EUL" is the valid solution.
