# Question TCS_LOG_229 — Explanation

**Correct Answer: Option A ({ 3,4,5})**

### Topic
Logical Reasoning > Venn Diagrams

### Question
Set A = {1,2,3,4,5}, Set B = {3,4,5,6,7}. What is A∩B?

### Options
- (A) { 3,4,5}
- (B) {1,2,6,7}
- (C) {1,2,3,4,5,6,7}
- (D) {3,5}

### Explanation
Option (A) is the correct answer. In Venn Diagrams, evaluating the given problem conditions confirms that "{ 3,4,5}" is the valid solution.
