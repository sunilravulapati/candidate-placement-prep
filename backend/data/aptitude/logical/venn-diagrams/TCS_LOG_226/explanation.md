# Question TCS_LOG_226 — Explanation

**Correct Answer: Option A (45)**

### Topic
Logical Reasoning > Venn Diagrams

### Question
In a Venn diagram with two circles A and B overlapping: region (A only) = 15, (B only) = 20, (both) = 10. Total elements = ?

### Options
- (A) 45
- (B) 35
- (C) 30
- (D) 50

### Explanation
Option (A) is the correct answer. In Venn Diagrams, evaluating the given problem conditions confirms that "45" is the valid solution.
