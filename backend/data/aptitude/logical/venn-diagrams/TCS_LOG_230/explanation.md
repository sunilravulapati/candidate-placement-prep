# Question TCS_LOG_230 — Explanation

**Correct Answer: Option A ({a,b,c,d,e,f})**

### Topic
Logical Reasoning > Venn Diagrams

### Question
Set A = {a,b,c,d}, Set B = {c,d,e,f}. What is A∪B?

### Options
- (A) {a,b,c,d,e,f}
- (B) {c,d}
- (C) {a,b}
- (D) {e,f}

### Explanation
Option (A) is the correct answer. In Venn Diagrams, evaluating the given problem conditions confirms that "{a,b,c,d,e,f}" is the valid solution.
