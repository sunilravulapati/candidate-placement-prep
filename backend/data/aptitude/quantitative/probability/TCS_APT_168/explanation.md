# Question TCS_APT_168 — Explanation

**Correct Answer: Option A (2/15)**

### Topic
Numerical Ability > Probability

### Question

### Options
- (A) 2/15
- (B) 4/10
- (C) 1/5
- (D) 3/15

### Explanation
Option (A) is the correct answer. In Probability, evaluating the given problem conditions confirms that "2/15" is the valid solution.
