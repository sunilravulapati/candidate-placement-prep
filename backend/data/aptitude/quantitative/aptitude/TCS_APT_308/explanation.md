# Question TCS_APT_308 — Explanation

**Correct Answer: Option A (2h)**

### Topic
Numerical Ability > Aptitude

### Question
Two trains run toward each other at 60 km/h and 90 km/h. Distance 300 km. Time to meet?

### Options
- (A) 2h
- (B) 3h
- (C) 1.5h
- (D) 2.5h

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "2h" is the valid solution.
