# Question TCS_APT_278 — Explanation

**Correct Answer: Option A (x=6, y=4)**

### Topic
Numerical Ability > Aptitude

### Question
x + y = 10, x - y = 2. Find x and y.

### Options
- (A) x=6, y=4
- (B) x=4, y=6
- (C) x=7, y=3
- (D) x=5, y=5

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "x=6, y=4" is the valid solution.
