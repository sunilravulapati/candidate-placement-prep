# Question TCS_APT_303 — Explanation

**Correct Answer: Option A (6000)**

### Topic
Numerical Ability > Aptitude

### Question
A, B, C invest in ratio 1:2:3. Total profit is Rs 12000. C's share?

### Options
- (A) 6000
- (B) 4000
- (C) 2000
- (D) 3000

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "6000" is the valid solution.
