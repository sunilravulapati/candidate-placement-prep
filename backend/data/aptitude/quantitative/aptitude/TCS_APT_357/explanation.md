# Question TCS_APT_357 — Explanation

**Correct Answer: Option C (8:9)**

### Topic
Numerical Ability > Aptitude

### Question
A started with Rs 2000 for 12m, B joined with Rs 3000 after 4m. Profit ratio A:B?

### Options
- (A) 2:1
- (B) 3:2
- (C) 8:9
- (D) 1:1

### Explanation
Option (C) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "8:9" is the valid solution.
