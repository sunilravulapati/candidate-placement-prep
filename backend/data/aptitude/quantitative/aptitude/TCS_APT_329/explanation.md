# Question TCS_APT_329 — Explanation

**Correct Answer: Option A (2)**

### Topic
Numerical Ability > Aptitude

### Question
A number when divided by 6 leaves remainder 5. The same number when divided by 3 leaves?

### Options
- (A) 2
- (B) 1
- (C) 0
- (D) 3

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "2" is the valid solution.
