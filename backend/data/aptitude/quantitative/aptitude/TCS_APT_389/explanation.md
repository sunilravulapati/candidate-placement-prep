# Question TCS_APT_389 — Explanation

**Correct Answer: Option A (Rs 20000)**

### Topic
Numerical Ability > Aptitude

### Question
Ratio of A's to B's salary is 5:4. If A gets Rs 5000 more, find B's salary if total = Rs 45000.

### Options
- (A) Rs 20000
- (B) Rs 25000
- (C) Rs 18000
- (D) Rs 22000

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "Rs 20000" is the valid solution.
