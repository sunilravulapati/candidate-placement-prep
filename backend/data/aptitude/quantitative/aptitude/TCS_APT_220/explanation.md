# Question TCS_APT_220 — Explanation

**Correct Answer: Option A (360)**

### Topic
Numerical Ability > Aptitude

### Question
A student scored 72% in an exam. If full marks = 500, find the marks obtained.

### Options
- (A) 360
- (B) 350
- (C) 380
- (D) 370

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "360" is the valid solution.
