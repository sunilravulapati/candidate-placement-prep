# Question TCS_APT_355 — Explanation

**Correct Answer: Option A (90°)**

### Topic
Numerical Ability > Aptitude

### Question

### Options

- (B) 60°

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "90°" is the valid solution.
