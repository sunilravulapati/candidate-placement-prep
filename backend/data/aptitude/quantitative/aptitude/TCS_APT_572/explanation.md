# Question TCS_APT_572 — Explanation

**Correct Answer: Option A (0.96)**

### Topic
Numerical Ability > Aptitude

### Question

### Options

- (B) 1.5
- (C) 0.8

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "0.96" is the valid solution.
