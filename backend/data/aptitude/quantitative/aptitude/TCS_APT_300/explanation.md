# Question TCS_APT_300 — Explanation

**Correct Answer: Option A (1875)**

### Topic
Numerical Ability > Aptitude

### Question

### Options

- (B) 1500

- (D) 1200

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "1875" is the valid solution.
