# Question TCS_APT_330 — Explanation

**Correct Answer: Option A (74)**

### Topic
Numerical Ability > Aptitude

### Question
The sum of digits of a two digit number is 11. If digits reversed, number decreases by 27. Number?

### Options
- (A) 74
- (B) 65
- (C) 83
- (D) 56

### Explanation
Option (A) is the correct answer. In Aptitude, evaluating the given problem conditions confirms that "74" is the valid solution.
