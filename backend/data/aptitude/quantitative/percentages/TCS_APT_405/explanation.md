# Question TCS_APT_405 — Explanation

**Correct Answer: Option A (200)**

### Topic
Numerical Ability > Percentages

### Question
If 75% of a number exceeds 45% by 60, the number is:

### Options
- (A) 200
- (B) 150
- (C) 180
- (D) 250

### Explanation
Option (A) is the correct answer. In Percentages, evaluating the given problem conditions confirms that "200" is the valid solution.
