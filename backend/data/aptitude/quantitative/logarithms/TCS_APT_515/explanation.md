# Question TCS_APT_515 — Explanation

**Correct Answer: Option A (1.079)**

### Topic
Numerical Ability > Logarithms

### Question
If log(2) = 0.301 and log(3) = 0.477, find log(12).

### Options
- (A) 1.079
- (B) 1.1
- (C) 1.05
- (D) 1.2

### Explanation
Option (A) is the correct answer. In Logarithms, evaluating the given problem conditions confirms that "1.079" is the valid solution.
