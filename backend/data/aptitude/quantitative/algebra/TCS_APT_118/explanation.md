# Question TCS_APT_118 — Explanation

**Correct Answer: Option D (±8)**

### Topic
Numerical Ability > Algebra

### Question
For what value of k does 2x2 + kx + 8 = 0 have equal roots?

### Options
- (A) 8
- (B) 4
- (C) −8
- (D) ±8

### Explanation
Option (D) is the correct answer. In Algebra, evaluating the given problem conditions confirms that "±8" is the valid solution.
