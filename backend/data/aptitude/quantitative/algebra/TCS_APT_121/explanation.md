# Question TCS_APT_121 — Explanation

**Correct Answer: Option A (x + 2)**

### Topic
Numerical Ability > Algebra

### Question
Simplify (x2 − 4)/(x − 2).

### Options
- (A) x + 2
- (B) x − 2
- (C) x2 + 2
- (D) 2x

### Explanation
Option (A) is the correct answer. In Algebra, evaluating the given problem conditions confirms that "x + 2" is the valid solution.
