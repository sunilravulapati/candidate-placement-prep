# Question TCS_APT_122 — Explanation

**Correct Answer: Option A (4:3)**

### Topic
Numerical Ability > Algebra

### Question
If 3a = 4b, find the ratio a:b.

### Options
- (A) 4:3
- (B) 3:4
- (C) 1:1
- (D) 2:3

### Explanation
Option (A) is the correct answer. In Algebra, evaluating the given problem conditions confirms that "4:3" is the valid solution.
