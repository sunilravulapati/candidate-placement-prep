# Question TCS_APT_459 — Explanation

**Correct Answer: Option A (One solution: x=1)**

### Topic
Numerical Ability > Algebra

### Question
Find the number of solutions: |x - 3| = x + 1

### Options
- (A) One solution: x=1
- (B) Two solutions: x=1 and x=−2 rejected
- (C) Infinitely many
- (D) No solution

### Explanation
Option (A) is the correct answer. In Algebra, evaluating the given problem conditions confirms that "One solution: x=1" is the valid solution.
