# Question TCS_APT_506 — Explanation

**Correct Answer: Option A (90°)**

### Topic
Numerical Ability > Mensuration

### Question
The angle in a semicircle is always:

### Options
- (A) 90°
- (B) 60°
- (C) 180°
- (D) 45°

### Explanation
Option (A) is the correct answer. In Mensuration, evaluating the given problem conditions confirms that "90°" is the valid solution.
