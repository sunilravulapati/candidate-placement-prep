# Question TCS_APT_485 — Explanation

**Correct Answer: Option A (20-30)**

### Topic
Numerical Ability > Data Interpretation

### Question
A histogram shows frequency: 0-10: 5, 10-20: 8, 20-30: 12, 30-40: 7. Mode class interval:

### Options
- (A) 20-30
- (B) 10-20
- (C) 30-40
- (D) 0-10

### Explanation
Option (A) is the correct answer. In Data Interpretation, evaluating the given problem conditions confirms that "20-30" is the valid solution.
