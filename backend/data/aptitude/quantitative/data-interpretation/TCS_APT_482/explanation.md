# Question TCS_APT_482 — Explanation

**Correct Answer: Option A (50%)**

### Topic
Numerical Ability > Data Interpretation

### Question
Bar chart shows production: 2020=500, 2021=600, 2022=750. % increase from 2020 to 2022?

### Options
- (A) 50%
- (B) 40%
- (C) 60%
- (D) 55%

### Explanation
Option (A) is the correct answer. In Data Interpretation, evaluating the given problem conditions confirms that "50%" is the valid solution.
