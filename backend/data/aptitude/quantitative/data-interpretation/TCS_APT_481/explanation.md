# Question TCS_APT_481 — Explanation

**Correct Answer: Option A (90°)**

### Topic
Numerical Ability > Data Interpretation

### Question
In a pie chart, if a sector represents 25%, its central angle is:

### Options
- (A) 90°
- (B) 72°
- (C) 45°
- (D) 120°

### Explanation
Option (A) is the correct answer. In Data Interpretation, evaluating the given problem conditions confirms that "90°" is the valid solution.
