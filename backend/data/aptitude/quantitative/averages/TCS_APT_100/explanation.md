# Question TCS_APT_100 — Explanation

**Correct Answer: Option A (56)**

### Topic
Numerical Ability > Averages

### Question
The average of 10 numbers is 45. If one number is included, the new average is 46. The included number is:

### Options
- (A) 56
- (B) 50
- (C) 60
- (D) 55

### Explanation
Option (A) is the correct answer. In Averages, evaluating the given problem conditions confirms that "56" is the valid solution.
