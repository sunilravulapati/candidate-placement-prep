# Question TCS_APT_102 — Explanation

**Correct Answer: Option A (24)**

### Topic
Numerical Ability > Averages

### Question
Average of 7 numbers is 8. If each number is multiplied by 3, the new average is:

### Options
- (A) 24
- (B) 21
- (C) 18
- (D) 27

### Explanation
Option (A) is the correct answer. In Averages, evaluating the given problem conditions confirms that "24" is the valid solution.
