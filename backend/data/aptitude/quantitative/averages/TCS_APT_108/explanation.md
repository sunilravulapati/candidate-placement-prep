# Question TCS_APT_108 — Explanation

**Correct Answer: Option A (73)**

### Topic
Numerical Ability > Averages

### Question
In a class of 40 students, boys' average marks is 70 and girls' is 75. If girls are 60% of class, what is class average?

### Options
- (A) 73
- (B) 72
- (C) 74
- (D) 71

### Explanation
Option (A) is the correct answer. In Averages, evaluating the given problem conditions confirms that "73" is the valid solution.
